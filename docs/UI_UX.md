# UI/UX

## Direção visual

- linguagem doméstica, calma e direta;
- verde profundo como base, lima para progresso e laranja para ações/destaques;
- tipografia forte, superfícies claras e pouco ruído visual;
- pt-BR em todo texto de produto;
- estados nunca dependem somente de cor.

## Experiência mínima por tela

- carregamento compreensível;
- vazio com próxima ação;
- erro seguro e tentativa novamente quando aplicável;
- sucesso explícito;
- foco visível, labels e navegação por teclado;
- layout funcional em celular, tablet e desktop.
